# How AI was used

All original application code in this project was generated by AI coding
assistants under my direction. AI also generated or revised the automated tests,
documentation, packaging, and release setup, and was used for debugging and code
review.

I am not a programmer and did not independently write or audit the implementation.
My contribution was defining the goals, design requirements, and intended
workflow; directing revisions; and inspecting processed images against their
source photographs. I reported problems with cutout edges, missing stems, color,
detail, and front/rear positioning, then evaluated successive results.

The tool grew out of that practical workflow. Automated checks and AI code review
have been used to find bugs and check behavior, but this project has not received
an independent human code or security audit. Tests cover the cases described in
the repository; they do not establish correctness for every image, camera,
platform, or use case. Outputs still need visual review.

The existing third-party libraries used by the application were developed by
their respective contributors and have their own licenses. Their work is credited
in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Development provenance versus runtime behavior

AI was used to develop this software. The desktop also uses pretrained models
locally: SAM 2.1 for scan selections and BiRefNet Lite for detailed 2D cutouts.
Their weights and CPU runtimes are included in portable downloads. Processing
does not call an AI service, download model code, generate replacement texture
detail, or upload photographs. Source setup downloads dependencies and pinned
model files separately. Captured color remains the texture source.

## Desktop scan workflow

The desktop GUI, scan-mask processing, review fixes and packaging were also
implemented with AI assistance under the same disclosure. The scan workflow
uses the third-party SAM 2.1 model locally for inference. The image-cutout
workflow uses BiRefNet Lite by default in portable builds; the older plain
background extractor remains available. Model predictions can omit subjects,
retain backing or lose fine detail. Reported regression/runtime tests do not
establish universal mask quality or independent expert acceptance.
