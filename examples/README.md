# Reproducible synthetic examples

These inputs are procedural illustrations generated by Python/Pillow. They are
not camera photographs, generative-AI images, or evidence of real-photograph
extraction quality. They are distributed under the repository's MIT license.
No private development photographs or game assets are included.

- `photo/synthetic_pendant.png`: one opaque orange pendant on a plain background,
  including an opening and a cast shadow. This exercises the photo route on a
  controlled, non-leaf shape.
- `artwork/synthetic_tokens.png`: disconnected, already-transparent illustrations.
  The artwork preset retains both pieces and their authored color.

After installing the package, run from the repository root:

```text
cutout-prep examples/photo --size 512 --padding 24
cutout-prep examples/artwork --preset artwork --size 512 --padding 24
```

Outputs go into each selected folder's `Processed` subfolder. The automatic photo
case exits with `2` to request visual review even when its export succeeds; read
its report and preview. Generated processing reports/exports are ignored by Git.

To regenerate the included inputs and the combined README illustration:

```text
python examples/generate_examples.py
python examples/render_demo.py
```

The generator rewrites these named fixture inputs. Keep your own authored assets
outside the example paths. The demo renderer uses temporary processing folders
and writes `docs/images/synthetic-demo.jpg`.
